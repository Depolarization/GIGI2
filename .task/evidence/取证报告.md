## 🔴 真机 P0 bug（本次取证核心发现）

`CredentialStore.save()`（CredentialStore.kt:32）在真机 AndroidKeyStore(keystore2) 上必崩：
密钥 `setRandomizedEncryptionRequired(true)` 却以调用方 IV 初始化加密
→ `java.security.InvalidAlgorithmParameterException: Caller-provided IV not permitted`
（logcat 崩溃栈已捕获：FATAL EXCEPTION main, Process com.gigi.tcg，栈顶 CredentialStore.save:32）。
**影响：真机扫码登录 finalize 成功后 App 即崩溃，凭据无法落盘。**
修复建议（交回主线，本次未改业务代码）：加密 init 不传 IV（`cipher.init(ENCRYPT_MODE, key)`，`cipher.iv` 回读真实 IV——save() 里其实已经写了回读逻辑，只需删掉 spec 传入）；或解密侧兼容双格式。
取证绕行：DebugCredentialInjector 在取证侧按同一磁盘格式（gigi_credentials/ciphertext=Base64(IV+密文)、别名 gigi_credentials_key）用 Keystore 自生成 IV 正确写入，App 端解密读取成功（04 图的失效提示即证明解密链路工作）。

次要：`CredentialStore.clear()/save()` 用 `apply()`，instrumentation 进程退出早于 QueuedWork 刷盘会丢写（真机 Activity 生命周期下正常，非业务缺陷；注入器已改 `commit()`）。

## 偏离清单（设计与实现不符 / 取证受限项）

1. **首页"最近对局"区恒空白（P1 渲染 bug）**：HomeRoute.kt:131-136 Box 高度 = `viewportPx.height - lazyTopPx.height`，而两个 onSizeChanged 都挂在同一个 Box 上（lazyTop 永远是 Box 自身相对父级偏移≈0 且首帧 viewport 未测得→高度恒 0），Content/EmptyState 均被裁为 0 高不可见；刷新、滚动、切服重进均复现。对照：渠道服下该块 Error 态反而可见（走了另一分支），证明是 Content/Empty 布局测量缺陷而非无数据。未改业务代码，交回主线。
2. **首页无下拉刷新**：设计清单"下拉刷新（若有）"→ 实现为"对局主页"标题右侧刷新按钮（已取证点击生效），无 PullToRefresh。
3. **卡面 GIF 态预览空白**：切"动态卡面(GIF)"后选中态✓、下载按钮可用✓，但 AsyncImage 不渲染（PNG 切回即恢复）→ 疑缺 coil-gif ImageDecoder 接线。
4. **排行榜无赛季/版本筛选**：设计清单"切赛季/版本筛选（若有）"→ 实现仅有巅峰/赛事两 Tab。
5. **关于弹窗文案未本地化到 App 形态**："形态：网页应用——浏览器打开即用"仍为 Web 版文案。
6. **魔物牌 Tab 无筛选行**：仅角色/行动两分类有筛选器（与设计一致则忽略，记录事实）。
7. **下载成功 Toast 未入镜**：下载→Toast 间隔 > 截图耗时（screencap ~1.5s），三次抢拍未命中；以文件系统 + MediaStore 双证据替代（验收门槛③满足）。
8. **设备 IME 不接收中文 `input text`**（`%E5%89%91` 以字面写入搜索框）：搜索实时过滤行为已由空态结果证实，中文命中用例未取证。
9. **切回官服后落在卡牌统计页**：GigiNavHost `startRoute` 记住的是"上一次切换前的 Tab"（rank），切换后又被引导至 cardstats，二次切换未刷新 startRoute 语义（小瑕疵，不影响数据正确性）。
